# Flowia — GitHub Pages Deployment

Bu klasörü GitHub'a push ederek Privacy Policy ve Landing Page'i yayına alabilirsiniz.

## Adımlar

1. GitHub'da yeni bir repository oluşturun: flowia-site
2. Bu github-pages/ klasörünün içindeki tüm dosyaları push edin
3. Repository Settings → Pages → Source: Deploy from branch → main → / (root)
4. Birkaç dakika sonra siteniz şu adreste yayında olur:
   https://KULLANICI_ADINIZ.github.io/flowia-site/

## Klasör Yapısı
- index.html          → Ana landing page
- privacy-policy.html → Gizlilik politikası (TR + EN)
- terms-of-service.html → Kullanım koşulları (TR + EN)
- _config.yml         → GitHub Pages Jekyll ayarları
